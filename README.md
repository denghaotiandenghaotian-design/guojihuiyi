# 国际学术会议英语与跨文化交流 · 在线学习系统

基于骆洪《国际学术会议英语与跨文化交流》（云南大学出版社·研究生教学用书）构建的纯前端配套学习系统。

## 功能
- **23 个考点学习页**：Part I 会议英语实务 + Part II 跨文化交际（含 c3 理论专题、c4 案例分析）
- **双语对照**：160 段英文原文 + 同步中文翻译
- **教材习题**：103 道课后练习（填空/翻译/问答/写作/讨论/改错/案例），全部含答案与解析
- **题库**：490 题（单选/判断/多选/填空/简答/写作），0 重复
- **思维导图 + 艾宾浩斯间隔复习**：localStorage 持久化
- **20 套自动判分模拟卷**：每套 35 题（30 客观 + 5 主观）

## 本地运行
纯静态站点，无需构建。直接用浏览器打开 `index.html` 即可；或在本目录起任意静态服务器。

## 数据说明
原书为扫描版 PDF，本项目内容由三部分合并而成：① 用户提供的教材截图逐字录入；② 公开检索到的教材目录与跨文化交际题库；③ 依教材体例重构的同步练习。习题与案例均按单元归位，不冒充未核验的原文。
